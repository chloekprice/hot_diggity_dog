Hot-Diggity-Dog employs CoreML and Vision to accurately determine whether a given image depicts a hot dog.

The user can click on the camera icon in the top right corner and select an image from their photo album. The application will print "HOT-DIGGITY-DOG" if the image does, in fact, depict a hot dog and "HOT-DIGGITY-NAH" if it does not.
